{% blocktrans trimmed %} Thousand Suns Saga est un jeu de grande stratégie spatiale multijoueur, au tour par tour, qui se joue directement dans le navigateur. {% endblocktrans %}

{% blocktrans trimmed %} Vous incarnez le commandant d'une jeune civilisation, sur sa planète natale, au cœur d'un secteur de la galaxie partagé avec des dizaines d'autres joueurs. À vous de développer vos colonies, de faire tourner une économie exigeante, d'explorer les systèmes voisins, de faire progresser la science de votre peuple et de trouver votre place parmi les autres civilisations : par le commerce, par la diplomatie, par la parole… ou par la force. {% endblocktrans %}

{% blocktrans trimmed %} Une partie est une saga : elle se vit sur la durée, quelques minutes par jour, et c'est son histoire, écrite par les joueurs eux-mêmes, qui en fait tout le sel. {% endblocktrans %}

{% trans "1. Serveurs et commandants" %}

{% blocktrans trimmed %} Chaque partie se déroule sur un serveur, avec sa propre galaxie et ses propres joueurs. Sur chacun, vous créez un commandant : son nom, son portrait, le nom et le drapeau de sa civilisation. Un seul commandant par serveur, mais rien ne vous empêche de jouer sur plusieurs serveurs à la fois. {% endblocktrans %}

{% trans "Deux formats de partie existent :" %}

  • {% blocktrans trimmed %} Saga : le format principal. La partie dure des mois, à raison d'un cycle par jour, qui se termine à heure fixe. {% endblocktrans %}
  • {% blocktrans trimmed %} Escarmouche : une partie courte, à la manière d'un jeu de plateau. Le cycle se termine dès que tous les joueurs se sont déclarés prêts. {% endblocktrans %}

{% blocktrans trimmed %} Certains serveurs sont exclusifs : des parties sérieuses qui demandent beaucoup d'implication, et sur lesquelles vous ne pouvez avoir qu'un seul commandant à la fois. Les autres sont libres et se jouent en plus de vos autres parties. Selon le serveur, le roleplay est obligatoire ou simplement encouragé. {% endblocktrans %}

{% blocktrans trimmed %} Quand une partie se termine, ou que votre civilisation disparaît, vous gardez l'accès à votre commandant en consultation, et l'Assemblée Sectorielle de chaque serveur reste lisible par tous dans les Archives. {% endblocktrans %}

{% trans "2. Les cycles" %}

{% blocktrans trimmed %} Le temps de TSS avance par cycles. Pendant un cycle, vous donnez vos ordres à votre rythme : lancer une recherche, construire un district, ajuster la production d'un bâtiment, négocier avec vos voisins… À la fin du cycle, le serveur résout tout en même temps : vos usines produisent, votre population consomme, vos chantiers et vos recherches avancent. {% endblocktrans %}

{% blocktrans trimmed %} Chaque fin de cycle vous apporte ses rapports : ce qui a été produit, ce qui a manqué, ce qui a été découvert, et les événements qui ont touché votre civilisation. {% endblocktrans %}

{% blocktrans trimmed %} Vous vous absentez quelques jours ? Passez en mode absent : les cycles ne vous attendront pas, et votre empire continue de tourner sans vous. {% endblocktrans %}

{% trans "3. La galaxie" %}

{% blocktrans trimmed %} La carte d'un serveur est générée à sa création : une grille de secteurs, chacun découpé en quadrants et peuplé de centaines de systèmes stellaires, avec leurs étoiles, leurs planètes, leurs lunes et leurs ceintures d'astéroïdes. {% endblocktrans %}

{% blocktrans trimmed %} Les secteurs n'ont pas tous le même visage. Les civilisations naissent dans des secteurs natifs, entourées de leurs premiers voisins. Plus loin, on trouve des secteurs sauvages riches mais dangereux, des amas denses, des régions presque vides… {% endblocktrans %}

{% blocktrans trimmed %} Les planètes accueillantes sont rares, et les mondes de type Gaïa le sont encore plus. D'autres systèmes valent le détour pour leurs gisements de minerais, leurs géantes gazeuses ou leurs curiosités scientifiques. Certains, enfin, sont à éviter. {% endblocktrans %}

{% blocktrans trimmed %} Explorer, c'est choisir où s'étendre, et donc qui l'on aura pour voisin. {% endblocktrans %}

{% trans "4. Les colonies" %}

{% blocktrans trimmed %} Votre civilisation commence avec une seule colonie, sa capitale. D'autres viendront : du simple avant-poste à la mégalopole, en passant par la cité, le territoire et la métropole. Plus une colonie grandit, plus elle peut accueillir de districts. {% endblocktrans %}

{% blocktrans trimmed %} Les districts sont les quartiers de vos colonies : habitations, agriculture, industrie, extraction, science, armée… Chacun offre des emplacements pour des bâtiments : fermes, centrales, mines, usines, laboratoires. Vous pouvez régler l'activité de chaque bâtiment, pour économiser une ressource qui se fait rare ou relancer une production en retard. {% endblocktrans %}

{% blocktrans trimmed %} Et derrière tout cela, il y a une population : des habitants à loger, à nourrir, à soigner, à transporter et à alimenter en énergie, des travailleurs pour vos bâtiments, et un bonheur qui ne se décrète pas. {% endblocktrans %}

{% trans "5. L'économie" %}

{% blocktrans trimmed %} L'économie est le cœur de TSS. Les ressources se répartissent en grandes familles : {% endblocktrans %}

  • {% trans "Population : nourriture, eau, oxygène, biens de consommation, vêtements, médecine" %}
  • {% trans "Infrastructure : construction, transports, outils" %}
  • {% trans "Énergie" %}
  • {% trans "Matières premières : minerais, alliages, produits intermédiaires" %}
  • {% trans "Industrie et électronique : composants, ordinateurs" %}
  • {% trans "Illicites : drogues, organes de contrebande, IA illégales…" %}

{% blocktrans trimmed %} Rien ne se produit à partir de rien : une usine consomme des matières premières et de l'énergie, et demande des travailleurs. Une économie qui tourne, ce sont des chaînes de production bien équilibrées, de la mine jusqu'au produit fini. {% endblocktrans %}

{% blocktrans trimmed %} Les besoins de votre population évoluent avec votre civilisation : un peuple qui découvre la haute technologie n'attend plus les mêmes biens qu'une colonie de pionniers. Satisfaire ces besoins rend vos habitants heureux. Les négliger a des conséquences. {% endblocktrans %}

{% trans "6. Les technologies" %}

{% blocktrans trimmed %} La recherche débloque de nouveaux bâtiments, de nouvelles ressources et des bonus pour votre civilisation. L'arbre technologique couvre tous les domaines : urbanisme, agriculture, énergie, biologie, cybernétique, industrie, armement… Chaque technologie a ses prérequis, parfois dans un tout autre domaine. {% endblocktrans %}

{% trans "Les technologies sont regroupées en grandes époques, chacune avec ses propres défis :" %}

  • {% trans "Low-tech : développer sa colonie, commencer à explorer son secteur, établir ses premières colonies." %}
  • {% trans "Middle-tech : tout explorer, coloniser massivement, créer des routes spatiales." %}
  • {% trans "High-tech : satisfaire tous les besoins de sa population, envoyer des colonisateurs au loin." %}
  • {% trans "Ultra-tech : faire face à de nouvelles menaces." %}
  • {% trans "Singularité : la fin du jeu." %}

{% blocktrans trimmed %} Les technologies sont légèrement aléatoires : leurs effets varient d'une partie à l'autre. Les meilleurs choix d'une saga ne seront pas forcément ceux de la suivante, et il faudra parfois s'adapter en cours de route. {% endblocktrans %}

{% trans "7. La diplomatie" %}

{% blocktrans trimmed %} Les joueurs se regroupent en ententes. Chaque civilisation fait d'abord partie de l'entente native de son secteur, aux côtés de ses voisins de naissance. Libre à elle, ensuite, de fonder ou de rejoindre d'autres ententes : économiques, militaires, politiques, scientifiques, religieuses… jusqu'à cinq à la fois. {% endblocktrans %}

{% blocktrans trimmed %} Le fondateur d'une entente en définit les rôles et ce que chacun peut y faire : inviter ou exclure des membres, modérer l'assemblée, gérer les finances, partager la vision radar ou le contrôle des flottes. On y entre sur invitation ou par candidature. {% endblocktrans %}

{% blocktrans trimmed %} Les ententes sont publiques, et chacun peut voir qui s'est allié à qui. Pour les projets qui doivent rester discrets, il y a les coalitions, avec leur assemblée privée. {% endblocktrans %}

{% trans "8. Communication et roleplay" %}

{% blocktrans trimmed %} Dans TSS, on parle beaucoup, et on parle en jeu, au nom de sa civilisation : {% endblocktrans %}

  • {% trans "L'Assemblée Sectorielle, ouverte à tous les commandants du serveur, où se jouent les grands débats." %}
  • {% trans "Les tavernes, des forums créés et animés par les joueurs eux-mêmes." %}
  • {% trans "Les assemblées de coalition, réservées à leurs membres." %}
  • {% trans "Les messages privés, pour les négociations en tête à tête." %}
  • {% trans "Le forum HRP, pour parler hors du jeu, sur les serveurs où le roleplay n'est pas obligatoire." %}

{% blocktrans trimmed %} Les commandants peuvent saluer les messages des autres : adapté, remarquable, drôle, ou d'un roleplay intéressant. Ces votes forgent le respect diplomatique de chacun, affiché à côté de son nom : une réputation qui se gagne par la qualité de ses interventions. {% endblocktrans %}
